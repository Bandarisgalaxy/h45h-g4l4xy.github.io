## Introduction

The **Rotation** challenge on PicoCTF demonstrates the Caesar cipher — specifically a rotation by 18 positions. By leveraging the known prefix format of PicoCTF flags (`picoCTF`), we can determine the exact rotation shift and decode the ciphertext without any brute force.

> **Challenge Description:** "The challenge provides an encrypted text file and asks us to decrypt it to reveal the flag."

## Solution Walkthrough

### Step 1: Download the Encrypted File

```bash
wget https://artifacts.picoctf.net/c/386/encrypted.txt
```

### Step 2: View the Encrypted Content

```bash
cat encrypted.txt
```

Output:
```
xqkwKBN{z0bib1wv_l3kzgxb3l_4k71n5j0}
```

### Step 3: Determine the Rotation Shift

All PicoCTF flags begin with `picoCTF`. The ciphertext begins with `xqkwKBN`.

Compare the first letters:

```
Cipher: x  q  k  w  K  B  N
Plain:  p  i  c  o  C  T  F
```

Calculate the shift: `x` (position 24) → `p` (position 16):

```
24 - 16 = 8  ... but going backward: 26 - 8 = 18 shift forward
```

Or more directly: `p` + 18 positions = `x`. Confirm: `i` + 18 = `q`, `c` + 18 = `k`. ✓

**The rotation key is 18.**

### Step 4: Decrypt Using `tr`

```bash
echo "xqkwKBN{z0bib1wv_l3kzgxb3l_4k71n5j0}" | tr 'A-Za-z' 'S-ZA-Rs-za-r'
```

**How `tr` applies ROT-18:**

- `A-Z` mapped to `S-ZA-R`: shifts uppercase by 18 (A→S, B→T, ..., H→Z, I→A, J→B, ..., Z→R)
- `a-z` mapped to `s-za-r`: same shift for lowercase

### Step 5: Retrieve the Flag

```bash
picoCTF{r0tat1on_d3crypt3d_4c71f5b0}
```

## Key Concepts

**Caesar Cipher — Known-Prefix Attack:**

When the flag format is known (`picoCTF`), determining the shift requires only comparing the first plaintext letter to the first ciphertext letter:

```
Shift = (ciphertext_position - plaintext_position) mod 26
Shift = (24 - 16) mod 26 = 8  ← shift for encryption (forward)
Decryption shift = 26 - 8 = 18  ← OR equivalently: apply ROT (26-8)=18
```

**General `tr` Template for Any ROT-N:**

```bash
# ROT-13 (N=13):
echo "text" | tr 'A-Za-z' 'N-ZA-Mn-za-m'

# ROT-18 (N=18):
echo "text" | tr 'A-Za-z' 'S-ZA-Rs-za-r'

# Formula: start uppercase at chr(ord('A') + N), wrap around
# Formula: start lowercase at chr(ord('a') + N), wrap around
```

**`tr` Alphabet Notation:**

For ROT-N, the target range is:
- Uppercase: `'[chr(A+N)-Z][A-chr(A+N-1)]'`
- For ROT-18: A+18=S, so: `S-ZA-R` (S through Z, then A through R)

## Security Insights

- **Caesar cipher is broken in ≤25 attempts:** With only 25 non-trivial rotation values, brute force requires at most 25 attempts. The known-prefix attack reduces this to zero attempts.
- **Known-plaintext attacks:** Whenever part of the plaintext is known (like a flag format), classical ciphers are instantly broken. Real cryptographic schemes must be secure even when significant plaintext is known.
- **Modern ciphers resist known-plaintext:** AES in any mode produces statistically random output — knowing any amount of plaintext gives no information about the key or other ciphertext.
- **`tr` is a powerful text transformation tool:** Beyond rotational ciphers, `tr` is useful for many shell processing tasks: character set conversion, case folding, and delimiter translation.

## Conclusion

The Rotation challenge reinforces that Caesar-variant ciphers are trivially solved when any plaintext pattern is known. The known flag format `picoCTF` provides an instant cribs attack — determining the full rotation shift from just the first letter. This challenge builds familiarity with the Linux `tr` command as a rapid cipher tool.
